# AGI Board — frontend

React SPA for AGI Board (Trello-style boards). Served as static assets from Cloudflare Workers; talks to the NestJS API over REST and to one Durable Object per open board over WebSocket.

## Commands

`pnpm dev` · `pnpm lint` · `pnpm typecheck` · `pnpm test` · `pnpm e2e` · `pnpm build` · `pnpm format`

Before saying a task is done, run `pnpm lint && pnpm typecheck && pnpm test` (and `pnpm e2e` when routes or auth flow changed).

## Sources of truth (in the parent repo `agi-board`)

- Product scope and roles: `../docs/proposal/proposal.md`. Do not build anything listed as out of scope there.
- Per-screen UI spec: `../specs/<NNN>-<slug>/spec.md` and `../docs/ui-pipeline/screens/`.
- Visual reference: `../docs/ui-pipeline/mockups/` (open `index.dc.html`); tokens come from `mockups/assets/tokens.css`.
- Init plan and route table: `../docs/frontend-init-plan.md`.

UI labels and messages are English and copied verbatim from the spec. Do not invent wording; if the spec has none, ask.

## Structure

- `src/app/`: router, providers, layouts, route guards.
- `src/features/<feature>/`: `pages/`, `components/`, `api.ts`, `hooks.ts`. Create a folder only when it has a file.
- A feature never imports another feature's internals. Shared code goes to `src/components/common/` or `src/lib/`.
- `src/components/ui/` is generated by shadcn (`pnpm dlx shadcn@latest add <name>`); avoid hand edits so it can be regenerated.
- Each page file starts with a comment naming its screen ID (e.g. `// WEB-07 Board`). Dialogs (WEB-D01…D17) are components, not routes.

## Rules

- Colors only via tokens (`src/styles/tokens.css`, mapped to Tailwind/shadcn in `src/styles/index.css`). Exceptions: the board label palette and the 10 board background colors, which are data.
- Server state uses TanStack Query through `src/lib/api.ts`; never call `fetch` directly (it adds cookies and the CSRF header).
- Permissions are enforced by the server. The client only hides or disables controls; 403/404 show WEB-13.
- Never reveal whether an email has an account (sign-up, reset, lockout look the same for every address).
- Logout is POST only.
- No dark mode, no i18n (not in scope).

## Git workflow

- Every change belongs to one Trello card; its number (`#123`) is the ticket ID.
- Commit subject: `<type>(<scope>): #<id> <Imperative summary>`, e.g. `feat(boards): #123 Add route guards`. Types: `feat`, `fix`, `refactor`, `perf`, `test`, `docs`, `style`, `build`, `ci`, `chore`, `revert`; scope is lowercase (feature or area, e.g. `auth`, `boards`, `deps`). The guard hook denies other formats. If the card number is unknown, ask the user.
- Pull/merge requests: use the `create-pr` skill. Title = the Trello card name exactly; description = Ticket link / What / Why / How tested / Screenshots / Risk.

## Claude Code hooks

`.claude/settings.json` runs two hooks (Node scripts in `.claude/hooks/`):

- `guard.mjs` (PreToolUse): denies force push, pushes or deletes on protected branches (`main`, `master`, `develop`, `staging`, `production`), history rewrites, commits not in the `<type>(<scope>): #<id> <summary>` format, dangerous shell commands, touching `.env*` / `.dev.vars` / keys, and hand edits of `pnpm-lock.yaml`. Asks first for local data loss (`reset --hard`, `clean -f`, discard changes, rebase, amend), deploys, and edits of shared config, `.claude/`, `.github/`, `src/components/ui/`, `tokens.css`.
- `format.mjs` (PostToolUse): runs the project's Prettier on each file written or edited.

If a guard decision is wrong, fix the rule in `guard.mjs`, add a case to `guard.test.mjs`, and run `pnpm test:hooks`. Do not work around a deny.
