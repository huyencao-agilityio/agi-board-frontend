# Implementation Plan: #23 Implement feature Create Board

**Branch**: `feat/23-implement-feature-create-board` | **Date**: 2026-11-27 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/23/spec.md` (Trello card #23, clarified 2026-11-27), per-screen spec `../specs/019-create-board/spec.md`, screen spec `../docs/ui-pipeline/screens/WEB-D01-create-board.md`, mockup `../docs/ui-pipeline/mockups/web/WEB-D01-create-board.html`.

## Summary

Add WEB-D01 `Create board`: an admin-only `Create new board` tile in each workspace on Home (WEB-03) and Workspace boards (WEB-04) opens a dialog with `Board title`, the workspace name (read-only), `Visibility` (`Workspace` default / `Private`, each with a hover/focus tooltip) and `Cancel` / `Create`. `Create` sends `POST /workspaces/:workspaceId/boards` `{ name, visibility }`, invalidates Home and the workspace query, then opens `/b/:id` (WEB-07).

The dialog follows the existing `CreateWorkspaceDialog` pattern (shadcn `Dialog`, RHF + zod `onChange`, spinner with sr-only label, failure banner, close ignored while pending). The only new UI dependency is the shadcn `tooltip` component (Radix is already installed).
